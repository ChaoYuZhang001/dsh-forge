# DSH Gate Catalog Preview

These files are generated from `matrix-targets.json` and public GitHub metadata. They are reviewable evidence for the Desktop Community Market Provider contract; they are not a live service.

Before adding `manifest.json` to Desktop, deploy this directory behind HTTPS and verify that `/manifest.json` and `/v1/plugins` return `application/json`. GitHub repository pages and raw file URLs are not treated as a production provider here. The generated entries preserve `pass`, `warn`, and `fail` status so a catalog consumer can decide whether to show, block, or review an item.
